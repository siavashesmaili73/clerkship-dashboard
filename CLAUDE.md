# Instructions for Claude

## QBank screenshots (UWorld, etc.)

When the user sends a QBank question screenshot, answer using this exact template:

**What screams the answer:**

* [Decisive clue 1] → [what it implies]
* [Decisive clue 2] → [what it implies]
* [Pertinent negative or timing] → [why it matters]

**Correct:** [letter]. [tested answer]: [why correct, linking clues to diagnosis, mechanism, and the exact question; Tx or next diagnostic step when relevant]
**Your answer:** [letter]. [selected answer]: [only if incorrect; why tempting, why wrong, what findings would support it]
**Other choices:** [brief bullets eliminating the remaining options]
**Next time:** [age/sex + decisive positives + pertinent negatives + timing], [actual question being tested]? >> [correct tested answer] => [brief diagnosis/mechanism]; Tx: [treatment when relevant]; Mx: [management or next diagnostic step when relevant]

Rules:

* No preamble. No "Exam focus" or "Similar presentations" sections unless asked.
* Bold section labels, key clues/values in bullets, and key terms/organisms/drugs in explanations.
* In the "Next time" line, bold only the 3 most decisive findings in the trigger block plus the tested answer. Do not over-bold.
* Trigger block uses the stem's exact wording, with the actual age, never "adult"/"kid".
* Every drug gets its brand name in parentheses.
* Use colons and commas, never dashes (no em/en dashes as punctuation), after "Correct" and before the question in the "Next time" line.
* Do not modify repo data for screenshots unless asked.
